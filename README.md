# JARVIS AI — Android-friendly prototype

A simple mobile web voice assistant built with HTML, CSS and JavaScript.

## Features
- Speech-to-text using the browser's Web Speech API
- Text-to-speech replies
- Basic commands: time, date, hello, open YouTube, open Google, joke
- Responsive futuristic interface

## Run on your phone
1. Extract the ZIP.
2. Open the folder in an editor such as Acode.
3. Preview `index.html` in Chrome.
4. Allow microphone permission.
5. Tap the microphone and speak.

For reliable microphone access, host the project on an HTTPS site (for example, GitHub Pages). Browser speech recognition support varies by device and browser.

## Important
This is version 1: it is a command-based prototype, not yet a full conversational AI. A real AI brain requires an API and a secure backend. Never put a private API key directly in `script.js` or any public GitHub repository.
